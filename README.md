## スライドの見方

`slides/index.html` を **ブラウザにドラッグ&ドロップ**するだけで開ける。
外部ライブラリもフォントも一切読み込んでいないので、ネット接続不要・オフラインで動く。

うまく表示されない場合（一部の環境でローカルファイルのJSがブロックされることがある）は、
ターミナルで以下を実行して `http://127.0.0.1:8777` を開く。

```bash
cd slides && python3 -m http.server 8777
```

### 操作方法

| 操作 | キー / 動作 |
|---|---|
| 次のスライド | `→` `↓` `Space` `PageDown` / 画面の右半分をクリック |
| 前のスライド | `←` `↑` `PageUp` / 画面の左半分をクリック |
| 最初 / 最後へ | `Home` / `End` |
| スライド一覧 | `O`（もう一度 `O` か `Esc` で閉じる）／左下の「一覧」ボタン |
| 全画面 | `F` ／ 右下のボタン |
| 印刷・PDF出力 | `P` |

- スマホ・タブレットでは左右スワイプでページ送りできる。
- URL末尾の `#16` のような番号で、特定のスライドを直接開ける（共有リンク用）。
- 画面下の操作バーは、マウスを動かさないと自動的に消える（発表時に邪魔にならない）。

### PDFで配る場合

`P` を押す → 印刷ダイアログで「PDFとして保存」。
用紙サイズは **1280×720px（16:9）**、**余白なし**、**背景グラフィックを印刷する** をONにすること。

## データの取り扱いについて（重要）

この資料では、**出典が辿れない数値は、どれだけ都合が良くても載せていない。**

- 一次ソースで確認できた数値のみ、断定的に記載
- 二次情報・小規模調査・事業会社のPR発の数値には、その旨を注記
- 当社の試算・推計は、**すべて「当社試算」「当社推計」と明記**

### 特に注意すべき点

1. **就活時間の削減効果（130h → 42h）は当社モデル試算**であり、外部調査値ではない。
   工程別の所要時間について信頼できる一次調査は存在しない。
   社数の前提（エントリー19.2社・ES提出10.7社）のみ実データ。
   **パイロット受講生への実測アンケート（n=30〜50）で差し替えることが最優先アクション。**

2. **収益シミュレーションはすべて仮置き**。受講生数・紹介成立率・手数料単価は未検証。
   原価・人件費を含む損益計算は本版に含まれていない。

3. **「内定率が上がる」を訴求に使わないこと**。大学生の卒業時点の内定率は既に98.8%。
   訴求すべきは「内定先の質・選択肢の数・就活にかける時間」。

4. 流通しているが**採用しなかった数値**：
   AI求人の増加率、AIスキルの年収プレミアム、新卒採用単価56.8万円（マイナビ）など。
   いずれも一次ソースに辿り着けなかったため不採用とした。

**数値を引用・改変する前に、必ず `research/research.md` の
「6. スライド作成時の"やってはいけない"チェックリスト」を確認すること。**
